# Native quality baseline

## Scope

Preserve Calcu Later's native UIKit identity, Traditional Chinese content,
three learning entrances and the supportive 梅西老師 character. Improve the
experience for children aged 5–8 rather than replacing it with a different game.

Baseline application source: `d90b4b4` on `main`.
Development branch: `polish/48h-2026-10-21`.

## Verification decision, before the first run

- No existing workflow or Simulator run is present in the repository.
- The editing host is Linux and cannot execute UIKit or Apple's Simulator.
- Use a standard `macos-15` GitHub-hosted runner. The repository is public;
  [GitHub documents standard public-repository runners as free](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
- Select Xcode 16.4 build 16F6, iOS Simulator SDK/runtime 18.5 and an owned
  iPhone 16. Fail visibly if that contract is unavailable; do not silently
  switch toolchains or download a new runtime.
- No project signing/capability changes, external game packages, credentials,
  deployment, releases, auto-merge or paid runners.
- Build, boot/readiness, test execution and evidence export are separate
  boundaries. Do not retry an unchanged failure without diagnosing the first
  failing stage and recording the discriminating change.
- Keep original results, screenshots and accessibility hierarchies.

## Baseline tap coverage

1. Home → settings → Done → home.
2. Lessons → first demonstration → practice → hint → back to lessons → home.
3. Drills → two wrong choices → hint → correct choice → home.
4. Stories → grade 1 → read story → reveal equation → hint → grade chooser → home.

The initial app changes are stable accessibility identifiers and labels, not
 a visual redesign. Screenshots will therefore represent the existing layout.
An XCTest tap pass does not by itself establish that text, hints and controls
are visually comfortable; inspect the retained screenshots too.

## Improvement priorities under review

1. Mathematical correctness of explanations, particularly remainder division.
2. Child-paced answer review instead of explanations disappearing on a timer.
3. Readable answer cards and compact-screen hints; reliable repeated input.
4. Coherent finite practice sessions, meaningful progress and retry support.
5. Content variety without duplicate-heavy lesson sessions.
6. Native accessibility, motion, speech and device-layout regression checks.
